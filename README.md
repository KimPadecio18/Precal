# Precal Notes

Teaching notes, lab exercises, quizzes, and mentorship material for **Precalculus (Precal)**, organized into a single, consistent repository.

## Repository structure

## What's in each folder

- **Module-Handouts/** — PDF handouts for each precal module/unit.
- **Class-Record/** — Archive of previous batches' quizzes and exams, organized by academic year (e.g. `AY 2025-2026/Quizzes/`). Currently empty; add a new AY folder each time a past batch's materials are archived.
- **Mentorship/** — Practice problems, exercises, and reference material used in one-on-one or small-group mentorship sessions, split by exam coverage (Midterm / Finals).
